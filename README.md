# StudyBuddies
This project aims to develop an online Study Invitation System that allows university students to create, join, and manage study sessions efficiently.

Through this platform, users can post invitations for study sessions (e.g., for specific courses or exams), join existing invitations created by others, and manage their participation within a shared study pool.

The system supports essential user interactions including account login, invitation creation, joining, leaving, and cancellation.
